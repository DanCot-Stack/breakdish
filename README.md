# BREAK DISH

A responsive, static first-stage website concept for BREAK DISH, a UK 8-ball pool community.

## Files
- `index.html` — page content and semantic structure
- `styles.css` — responsive premium dark, burgundy, gold and powder-blue visual styling
- `script.js` — mobile navigation and contact form preview behaviour

## Run locally
Open `index.html` in a browser, or serve this directory with any static web server.

## Deploy on Render
Create a **Static Site** and connect this GitHub repository:
- Build command: leave blank
- Publish directory: `.`

## Important launch notes
- Fixture rows, league table rows, player/team cards and news cards are clearly illustrative placeholders, not real results or claims.
- The contact form is currently a preview only. It does **not** transmit or save messages. Before launch, connect it to a backend/API and a suitable data store, and add spam protection and privacy information.
- The logo mark is a temporary CSS-built emblem, not a supplied official logo. Replace it with the official logo asset when available.
- Privacy, terms and cookies links currently point to the contact section; create proper policy pages before public launch.
- Replace placeholders with verified competition details and real imagery only when approved assets and information are available.

## Branding
Designed around a premium pool-hall palette: near-black, burgundy, metallic gold, cream and restrained powder blue. The table illustration uses UK-style red/amber balls and a black eight ball rather than American striped balls.
